# Hook Master 🪝

A Mediterranean-port pendulum crane game for [Playgama](https://playgama.com):
swing the hook, grab the crates, and stack them on the cargo ship before the
timer runs out. The ship rocks on the waves, the wind pushes your load, and
every level asks for a little more precision.

## How to play

- **HOLD LEFT / RIGHT** (or **A / D**, or tap the on-screen pads) to swing the
  crane hook like a pendulum.
- **GRAB** picks up the crate under the hook; **DROP** releases it over the
  ship's hold.
- Stack every crate **inside the dashed hold** before the timer ends. Crates
  that land outside the hold (or on a wobbly pile) fall into the sea and cost a
  heart.

## Depth curve (300 levels)

| Level | Mechanic |
|---|---|
| 1 | Basic pendulum + static ship |
| 15 | **Wind** pushes the hanging load |
| 30 | **Moving ship** — the cargo drifts along the dock |
| 45 | **Fragile crates** — don't drop them! |
| 75 | **Storms** — stronger wind, bigger waves |
| 90 | **Two docks** — crates on both sides |
| 120 | **Golden crates** — bonus coins when stacked |
| + | The hold narrows, the ship rocks harder, and the timer gets tighter |

## Features

- **150-300 levels** generated from a parametric spec with real, visible
  progression (new mechanics, tighter thresholds).
- **6 worlds** with fully distinct layered backgrounds (morning pier, sunny
  marina, golden sunset, coral cove, deep blue sea, moonlit bay).
- **PERFECT STACK** — land a crate centered in the hold for a bonus (the sweet
  spot flashes on the deck).
- **2.5D presentation**: layered parallax backgrounds, a pendulum that swings in
  screen space, and a ship that rocks on the water.
- **Shop** with illustrated items (Extra Heart, Extra Time, Coin Magnet, Golden
  Hook, Combo Boost) — buy with coins or watch a rewarded ad.
- **Win streaks** multiply coins up to ×3.
- **Ads**: interstitial after 2 same-outcome runs; rewarded for revive and shop
  items (reward granted only on `rewarded` state).
- **Playgama Bridge SDK v2** with defensive fallback — the game runs fully
  without the bridge (localStorage) and syncs progress via cloud storage when
  the bridge is present.
- **100% downloaded assets** (CC0 / OGA-BY / CC-BY — see
  [`assets/LICENSES.md`](assets/LICENSES.md)): nothing is generated by code.

## Run locally

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

The game needs an HTTP server (canvas textures are tainted under `file://`).

## QA

`tools/selftest.js` drives the full game flow headlessly (menu → gameplay →
grab/drop → victory → confetti → shop → game over → revive) and pixel-checks
the backgrounds, confetti and HUD:

```bash
cd tools && npm install && node run-selftest.js
```

## Playgama

`playgama-bridge-config.json` declares the SDK setup (interstitial after
consecutive runs, rewarded ads for revive / shop). The bridge script is loaded
from `https://bridge.playgama.com/v2/stable/playgama-bridge.js` before the game
scripts, exactly as Playgama requires.
